# SQL Task 2 - Student Database

## Description
This project demonstrates basic SQL operations including:
- Creating a table
- Inserting records
- Retrieving data

## Table Name
students

## Fields
- id (Primary Key)
- name (TEXT)
- age (INTEGER)
- email (TEXT)

## Operations Performed
- DROP TABLE IF EXISTS
- CREATE TABLE
- INSERT INTO students
- SELECT * FROM students

## Output
Displays student records after insertion.
